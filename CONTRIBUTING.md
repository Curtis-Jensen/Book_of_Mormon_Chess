# Contributing to Book of Mormon Chess

Thanks for your interest in contributing!

## Rules
- Do not push directly to the main branch
- Create a new branch for your changes
- Submit a Pull Request for review

## Guidelines
- Keep code clean and readable
- Follow existing patterns where possible
- Explain what your change does in the PR

## Important
By contributing, you agree that your contributions fall under the same license as the project (non-commercial use only).

Thanks for helping build the game!
